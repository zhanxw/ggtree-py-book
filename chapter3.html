Part I: Tree Data Input, Output and Manipulation

3. Exporting Tree with Data

Preserving node- and branch-level annotations during serialization allows reproducible archival and sharing across downstream phylogenetic tools such as FigTree without losing associated metadata.

3.1 Exporting Topologies via write_tree()

write_tree(phy, file=...) emits standard parenthetical Newick strings preserving internal node labels, branch lengths, and optional root stem edges.

3.2 Exporting Tree Data to BEAST Nexus &amp; JSON

write_beast() serializes any annotated TreeData—such as NHX species tags or PAML CodeML substitution statistics—into inline NEXUS [&...] metadata comments that read_beast() restores cleanly into mappable branch attributes, whereas write_jtree() / read_jtree() exchanges structured JSON tree objects.

import os
import tempfile

nhx = read_nhx(system_file("extdata", "NHX", "phyldog.nhx"))
mlc = read_codeml(
    system_file("extdata", "treeio", "PAML_Codeml", "rst"),
    system_file("extdata", "treeio", "PAML_Codeml", "mlc"),
)
with tempfile.TemporaryDirectory() as d:
    b1 = os.path.join(d, "nhx_beast.nexus")
    b2 = os.path.join(d, "mlc_beast.nexus")
    write_beast(nhx, file=b1)
    write_beast(mlc, file=b2)
    tr1 = read_beast(b1)
    tr2 = read_beast(b2)

p1 = (
    ggtree(tr1, aes(color="S"))
    + scale_color_continuous(low="#132B43", high="#56B1F7")
    + geom_tiplab(size=2.8)
    + geom_treescale(x=0.05, y=2.0)
    + hexpand(0.32)
)
p2 = (
    ggtree(tr2, aes(color="dN"))
    + scale_color_continuous(low="darkgreen", high="red")
    + geom_tiplab(size=3.0)
    + geom_treescale(x=0.2, y=1.5)
    + hexpand(0.24)
)
plot_list(p1, p2, ncol=1, nrow=2, tag_levels="A")
